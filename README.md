# Portal oficial Ayuntamiento de Rivas Vaciamadrid (datosabiertos-rivasciudad-es)

Portal oficial Ayuntamiento de Rivas Vaciamadrid is a open data portal open-data portal for Spain running **CKAN**, exposing a standardized catalog API over ~7 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/datosabiertos-rivasciudad-es/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=datosabiertos-rivasciudad-es-api-evangelist&utm_content=repo)
